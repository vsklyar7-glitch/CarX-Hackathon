# CityView2 — дождливый город

Существующий `CityView2` в `Assets/Scenes/Scene2.unity` настроен для ряда окон с противоположной стороны участка.

- Position `(1, -3, 45)`, Rotation `(0, 0, 0)`.
- Scale `(180, 100.46512, 1)`; пропорции исходной панорамы 2752 × 1536 сохранены. Фон находится примерно в 38 метрах за наружной стеной с окнами.
- Существующий материал `Assets/Materials/PoliceStation/CityView2.mat`: `Universal Render Pipeline/Unlit`, Base Color `(0.8, 0.8, 0.8, 1)`. Исходная Base Map сохранена; Tiling `(1,1)`, Offset `(0,0)`.
- На MeshRenderer отключены отбрасывание и приём теней, Light Probes и Reflection Probes. Изображение дождливого города не затемняется лампами участка.

Проверено рендером камеры в Unity 6000.6.8f1, вне Play Mode: центральное окно вблизи (`window-close.png`), крайние окна (`window-left.png`, `window-right.png`), общий вид (`after.png`) и вид через жалюзи из рабочей комнаты (`from-player-room.png`). На проверенных ракурсах панорама видна, края плоскости не появляются.

Scene2 сохранена через Unity. Временная камера и редакторский инструмент удалены. Освещение комнат и `CityVew1` не изменены. Play Mode и сборка приложения не запускались.

`Scene2.before.unity`, `CityView2.before.mat`, `before.png` — состояние перед настройкой, включая существующие пользовательские изменения.
