# Потолок и освещение участка

Сцена: `Assets/Scenes/Scene2.unity`.
Иерархия: `imagecheck / Ceiling and lighting`.

Четыре группы соответствуют существующим полам: `Main office`, `Meeting room`, `Side office`, `Reception`. Нижняя поверхность потолка находится на локальной высоте 3,12 м. Сетка потолочных плит имеет шаг 0,61 × 1,22 м и объединена в один меш на помещение.

В помещениях размещены 23 прямоугольных люминесцентных светильника. У каждого две светящиеся трубки `Glowing fluorescent tube 1/2` и дочерний `Downward room light` с компонентом `Light`. Позиции, пересекающие стены, пропущены.

Для настройки яркости выберите `Downward room light` и измените `Intensity` (исходно 3,5) или `Range` (5,5 м). Свет направлен вниз, `Spot Angle` — 115°. На одном светильнике в каждой зоне включены мягкие тени; остальные работают без теней для снижения нагрузки. Свет работает в реальном времени и не требует запекания.

Свечение самих ламп задаёт материал `Assets/Materials/PoliceStation/Warm_white_fluorescent.mat`, параметр `Emission`. Материалы потолка, направляющих и корпусов находятся в той же папке. Меши направляющих — в `Assets/Prefabs/PoliceStation`.

На потолке и корпусах есть статические коллайдеры. Rigidbody не добавлены. Назначать скрипты на GameObject не требуется.

Проверки: `ceiling-verification.txt` содержит результат создания; `playmode-verification.txt` — результат проверки в Play Mode, если она завершена; `ceiling-preview.png` — кадр из участка, если он получен. Отсутствие последних двух файлов означает, что проверка в Play Mode ещё не подтверждена.
