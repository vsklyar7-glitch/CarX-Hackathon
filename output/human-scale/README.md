# Человеческий масштаб Scene2

В `Assets/Scenes/Scene2.unity` установлен единый ориентир: 1 Unity unit = 1 метр. Масштаб выбран по мебели и высоте помещений, поэтому разная площадь локаций сохранена.

| Корневой объект | Scale X/Y/Z |
| --- | --- |
| `imagecheck` | 0.8 |
| `americannredotoday1` | 0.15 |
| `Basement` | 0.25 |

Положение корней локаций сохранено. Светильники, оконная рама и стекло масштабируются вместе со своей локацией. Дальность источников света уменьшена пропорционально масштабу.

В сцену добавлен существующий `InvestigationPlayer` с компонентом `PlayerController`. Начальная точка — участок. Прежняя отдельная камера отключена, чтобы работала камера игрока и не было двух AudioListener.

Общий префаб: `Assets/InteractionContent/Prefabs/InvestigationPlayer.prefab`.

- `PlayerController.walkSpeed`: 1.5 м/с.
- `PlayerController.runSpeed`: 3.5 м/с.
- `CharacterController.height`: 1.8 м.
- `CharacterController.radius`: 0.28 м.
- `CharacterController.center`: `(0, 0.9, 0)`.
- `CharacterController.stepOffset`: 0.28 м.
- `CharacterController.skinWidth`: 0.025 м.
- Камера: локальная высота 1.65 м, Field of View 70°, Near Clip Plane 0.04 м.

Для проверки откройте Scene2 и нажмите Play. Управление — WASD, мышь; Shift — ускорение, Esc — освобождение курсора, щелчок мышью — захват курсора.

В каждой локации есть дочерний `PlayerSpawn`. Для проверки другой локации выберите `Tools → Detective → Player spawn → Police station / Apartment / Basement`. Меню берёт текущую мировую позицию маркера, поэтому работает и после перемещения локации. В Play Mode перенос временный; вне Play Mode новая позиция игрока сохраняется вместе со сценой.

Новые скрипты на объекты назначать не нужно. `Assets/Editor/PlayerSpawnTools.cs` добавляет только редакторское меню переноса игрока и не входит в сборку. Логика PlayerController сохранена; изменено исходное значение скорости ходьбы. Параметры существующего префаба настроены через Unity.

`playmode-verification.txt` подтверждает движение реальным вводом W со скоростью 1.5 м/с, заземление, высоту глаз и остановку CharacterController перед препятствием во всех трёх локациях. Проверка также измерила максимальный подъём ступени подвала: 0.179 м. Из каждого помещения сохранён снимок с камеры игрока.
