# Вечерний город за окном Scene2

Настроен существующий объект `CityVew` (имя сохранено).

- Position: `(2.29, -2, -45)`, Rotation: `(0, 180, 0)`.
- Scale: `(140, 78.79187, 1)`. Пропорции взяты из исходного PNG 1672 × 941.
- Фон находится приблизительно в 35 метрах за окном комнаты появления игрока.
- Существующий `CityView_Material` переведён на `Universal Render Pipeline/Unlit`.
- Base Map сохранена: «Дождливый вечер над городом». Base Color: `(0.8, 0.8, 0.8, 1)`.
- На MeshRenderer отключены отбрасывание/приём теней и использование Light/Reflection Probes.

Проверено рендером камеры в Unity 6000.6.8f1, вне Play Mode: с позиции игрока, с двух сторон у окна и из глубины комнаты. На проверенных ракурсах город виден за жалюзи, края плоскости не видны. `after.png` — окончательный вид с позиции игрока, `room.png` — из глубины комнаты. `left.png` и `right.png` сделаны до уточнения вертикальных пропорций; горизонтальное покрытие не менялось.

Временная камера и редакторский инструмент проверки удалены. Игровые скрипты, положение игрока, геометрия окна и свет комнаты не изменены. Scene2 сохранена через Unity. Play Mode и сборка приложения в рамках этой задачи не запускались.

`Scene2.before.unity` и `CityView_Material.before.mat` — копии непосредственно перед настройкой; включают существовавшие пользовательские изменения. `before.png` — исходный ракурс с немного большим наклоном камеры вверх.
