# Три дня квартиры

Созданы отдельные сцены `Assets/Scenes/Day1.unity`, `Day2.unity`, `Day3.unity` по AGENTS.md и сюжетной концепции. Прямая просьба о раздельных сценах имеет приоритет над рекомендацией документа хранить состояния в одной сцене. Исходные Scene2 и InteractionDemo не изменены.

Предметы скопированы из экземпляров EvidenceItem в InteractionDemo, с их исходными ID, названиями, описаниями и геометрией. Папка дела относится к вступлению в участке и в квартиру не перенесена. Семейный договор исключён согласно AGENTS.md.

| Сцена | Новые улики | Изменения |
|---|---|---|
| Day1 | Семейная фотография, квитанция, ключ №17 | Тёплый приглушённый свет; закрытая дверь; остановившиеся часы |
| Day2 | Дневник Дмитрия, письмо Ивана | Старые улики сохранены; опрокинут стул, разбросаны бумаги; холодный свет, надпись «Ты открыл дверь»; лицо Алексея на фото зачёркнуто; часы идут назад |
| Day3 | Детский рисунок, записка отца | Предыдущие улики сохранены; дверь приоткрыта, за ней темнота и красноватый свет; надпись «Не вини себя»; слабый пульсирующий свет |

Фото и квитанция находятся на журнальном столике, ключ и письмо — на стойке, дневник — на приставном столике, рисунок — на полу рядом с журнальным столиком, записка отца — на столике. Фото во всех днях имеет один ID, поэтому существующий EvidenceJournal не дублирует его.

Как проверить: откройте нужную Day-сцену, нажмите Play, осматривайте предметы клавишей E. В каждой сцене уже настроены InvestigationPlayer, UI осмотра, коллайдеры и камера. Сцены добавлены в EditorBuildSettings; существующий порядок сцен сохранён.

На объекте `DayN — Story dressing` находится `ApartmentDayAtmosphere`: `day` задаёт характер света, `roomLights` — источники для мерцания, `clockMinuteHand` и `clockHourHand` — стрелки. Назначать компоненты вручную не требуется. Параметры и положение предметов можно менять прямо в сцене.

`ApartmentDaysBuilder` — редакторский генератор (Tools → Detective → Build apartment days). Он намеренно отказывается перезаписывать существующие Day-сцены, чтобы не потерять ручную работу.

Дверь является постановочным порогом с тёмным задником, а не проходом на отдельный уровень. Day3 сохраняет открытую позу двери; отдельной анимации открытия нет. Записи голоса, синхронизированные сюжетные события, автоматические переходы между днями и финальный выбор не подключены. Это три самостоятельно запускаемых состояния квартиры, готовые для дальнейшей сюжетной интеграции.

`playmode.txt` — результат проверки всех улик: свободная позиция капсулы человеческого роста, луч осмотра с учётом стен, открытие UI и защита от повторного добавления в блокнот. Day1.png–Day3.png — снимки из запущенных сцен.
