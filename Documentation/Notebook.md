# Блокнот улик

Экранный блокнот в виде раскрытой книги. Слева — иллюстрация, справа — название и описание. Один разворот показывает одну найденную улику; будущие улики не раскрываются.

## Запуск

1. Открыть `Assets/InteractionContent/InteractionDemo.unity` либо одну из существующих сцен с `PlayerInteraction`.
2. Нажать Play, осмотреть предмет через E.
3. J открывает и закрывает блокнот. Esc и кнопка «Закрыть» также закрывают его.
4. Клавиши ←/→ или кнопки на страницах перелистывают записи. На первой и последней записях соответствующая стрелка отключена. Повторные нажатия во время анимации игнорируются.

Во время перелистывания текст и изображение остаются на лицевой и обратной сторонах листа. Следующий разворот готовится заранее под текущими страницами. Противоположная старая страница сохраняется до завершения поворота, а оборот компенсирует поворот листа, чтобы текст не зеркалился. При закрытии посреди анимации временные копии удаляются; повторное открытие показывает целевой разворот целиком. Это плоский поворот листа без деформации бумаги.

Подключение автоматическое: `PlayerInteraction` добавляет `PlayerNotebook` к своему игроку. Тот загружает `Assets/Resources/NotebookCanvas.prefab`; вручную менять все сцены не нужно. Во время осмотра улики J открывает блокнот поверх осмотра. J, Esc и кнопка закрывают только блокнот и возвращают прежнее окно осмотра; персонаж остаётся заблокированным до закрытия самого осмотра. E во время чтения не закрывает нижнее окно. Открытие при внешней сюжетной блокировке управления по-прежнему запрещено.

## Настройка

- В `EvidenceItem` поле **Notebook Description** задаёт краткую заметку. Если оно пустое, используется обычное **Description**.
- **Image** задаёт собственную иллюстрацию. Если она не назначена, блокнот берёт спрайт `Resources/NotebookArt/<evidenceId>`.
- Окно осмотра использует ту же иллюстрацию с тем же приоритетом. При отсутствии картинки описание занимает свободное место; при наличии слева изображение, справа описание. Прежний столбец «Блокнот» скрыт, а снизу показана подсказка J. Ссылка на старый текстовый компонент сохранена для совместимости с существующими сценами.
- Текст страниц использует Marck Script с кириллицей: `Assets/Fonts/MarckScript/NotebookHandwriting.asset`. Алфавит заранее запечён в статический SDF-атлас; системный шрифт на компьютере не требуется. Исходный TTF и лицензия SIL OFL включены в проект. Кнопки и обозначения клавиш используют печатный шрифт для читаемости.
- Семейная фотография — отдельная сгенерированная иллюстрация. Остальные семь изображений получены рендером существующих моделей улик; сами модели сцены не заменены.
- Для семи рендеров камера подбирает масштаб по видимой геометрии каждого предмета: большая сторона занимает 90% квадратного кадра. Поля коллайдера в расчёт не входят. Это сохраняет крупный вид даже у небольшого ключа. Фотография не перекадрируется.
- В префабе `NotebookCanvas` можно менять оформление, тексты кнопок, шрифт, поля `NotebookView` и длительность анимации **Turn Duration**.
- **Tools → Detective → Build Notebook** пересобирает интерфейс по коду `NotebookBuilder`. Команда перезаписывает этот префаб, поэтому ручные изменения дизайна нужно также переносить в генератор. Существующие PNG иллюстраций сохраняются.

## Хранение данных

`EvidenceJournal.Pages` содержит копии ID, названий, описаний и ссылок на спрайты в порядке нахождения. Добавление через `Add(EvidenceItem)` не создаёт повторную страницу или повторное событие `EvidenceAdded`. Старые вызовы `Add(id, title)` и `Titles` продолжают работать. Журнал живёт между сценами до завершения запуска; сохранения на диск нет.

Пустой блокнот показывает инструкцию. Последняя открытая запись сохраняется при повторном открытии тем же игроком. При создании нового игрока в другой сцене страницы остаются, но выбранная запись начинается с первой.

## Проверка

В Play Mode свежей `InteractionDemo` выполнить через Unity CLI:

```powershell
unity command script run --file AgentScripts/VerifyNotebook.cs --entry VerifyNotebook.Run --project-path (Get-Location).Path
```

Проверка использует временные устройства ввода и восстанавливает их после выполнения. Проверяются живые кадры, J/Esc и кнопки, пустой журнал, блокировка WASD/мыши, восемь иллюстраций, описания, отсутствие дубликатов, границы страниц, перелистывание при `timeScale = 0`, защита от повторных нажатий и возврат из блокнота к осмотру. Отчёт — `output/notebook/verification.txt`, изображения — в той же папке.

`AgentScripts/VerifyNotebookModal.cs` (`VerifyNotebookModal.Run`) дополнительно проверяет кириллицу, размещение текста всех восьми страниц и вложенные окна: J, Esc, кнопку, игнорирование E, прежний курсор и блокировку, закрытие обоих окон программно. Отчёт и снимки — `output/notebook-handwriting`.

`AgentScripts/VerifyNotebookTurning.cs` (`VerifyNotebookTurning.Run`) проверяет содержимое обеих сторон во время движения, направление оси у корешка, подготовку следующего разворота, поворот при `timeScale = 0`, быстрые нажатия, закрытие посередине и отсутствие оставшихся временных копий. Отчёт — `output/notebook-turning/verification.txt`. Методы `PoseFront`/`PoseBack` намеренно ставят только тестовый Play Mode на паузу для съёмки промежуточных кадров.

После основной проверки `AgentScripts/VerifyNotebookTransfer.cs` (`VerifyNotebookTransfer.Run`) проверяет сохранность журнала при перезагрузке сцены и доступ к записям из нового экземпляра игрока. Обе проверки выполнены успешно в Unity 6000.6.8f1.
