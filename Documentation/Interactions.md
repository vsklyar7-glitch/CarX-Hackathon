# Предметы и взаимодействие

## Быстрый запуск

1. Открыть проект в Unity **6000.6.8f1** и дождаться компиляции.
2. Если папки `Assets/InteractionContent` ещё нет, сохранить текущую сцену и выполнить **Tools → Detective → Generate Interaction Content**. Генератор создаёт недостающие ассеты, существующие префабы и демосцену не перезаписывает.
3. Открыть `Assets/InteractionContent/InteractionDemo.unity`, нажать Play.
4. WASD — ходьба, мышь — обзор, Shift — бег. Подойти к предмету на столе, посмотреть на него и нажать **E**. **E**, **Esc** или кнопка «Закрыть» закрывают осмотр. В обычном режиме Esc освобождает курсор, ЛКМ захватывает его.

В демосцене восемь улик. Это простые редактируемые 3D-модели из геометрии Unity, предназначенные для прототипа, с материалами и коллайдерами. Фотография содержит схематичные фигуры, рисунок — фигуры и дверь. Модели можно позже заменить, сохранив корневой объект и компонент `EvidenceItem`.

## Подключение к игроку Дениса

Использован `PlayerController.cs` из `origin/Denis` (коммит добавления контроллера `f3c7c42`), сохранён GUID `92d58f2ac0d51b94bb2aff76e4abdf31` и публичные поля. Ввод адаптирован к установленному Input System; настройки проекта переключать на Old/Both не требуется. Добавлены `ControlsBlocked` и `SetControlsBlocked(bool)`.

Для готового игрока в сцене:

1. Сначала сгенерировать контент.
2. Выделить корневой объект с `PlayerController` и `CharacterController`.
3. Выполнить **Tools → Detective → Attach Interaction To Selected Player**.
4. Проверить `PlayerController → Player Camera`: Transform камеры. В `PlayerInteraction → Player Camera` должна стоять Camera той же камеры; `Inspection UI` — компонент на дочернем `InspectionCanvas`.
5. В сцене должен быть один `EventSystem` с `InputSystemUIInputModule`. Команда создаёт его, если отсутствует. Если в сцене уже старый StandaloneInputModule, заменить его на InputSystemUIInputModule.
6. Сохранить сцену. Команда поддерживает Undo и повторно компонент не добавляет.

Альтернатива — использовать уже связанный префаб `Assets/InteractionContent/Prefabs/InvestigationPlayer.prefab`. Установить его на пол. Не оставлять второго игрока, лишнюю активную камеру или AudioListener. Для кнопки осмотра нужен EventSystem в сцене; клавиши E/Esc работают независимо от него.

Никакие рабочие сцены команды генератором не заменяются. Демосцена отдельная; расстановка сюжетных улик по финальной квартире остаётся задачей сборки локации.

## Предметы

| Префаб | Evidence Id | Улика |
|---|---|---|
| CaseFile | case_file | Папка дела |
| FamilyPhoto | family_photo | Семейная фотография |
| Receipt | electricity_receipt | Квитанция за электричество |
| BasementKey | basement_key_17 | Ключ №17 |
| DmitryDiary | dmitry_diary | Дневник Дмитрия |
| IvanLetter | ivan_letter | Письмо Ивана |
| ChildDrawing | child_drawing | Детский рисунок |
| FatherNote | father_note | Записка отца |

Перетащить нужный префаб из `Assets/InteractionContent/Prefabs` в сцену. Локальная ось Y направлена вверх, предметы лежат на поверхности. Проверить высоту и BoxCollider. Параметры `Title`, `Description` и необязательный `Image` задаются в `EvidenceItem`. У разных улик должны быть разные непустые `Evidence Id`; копии одной улики используют тот же ID.

Чтобы сделать интерактивным существующий объект, добавить `EvidenceItem`, заполнить поля и подогнать его BoxCollider под модель. Декоративные дочерние меши не требуют собственных коллайдеров. Дальность задаётся в `PlayerInteraction → Interaction Distance` (2,2 м по умолчанию). `Raycast Mask` должна включать стены и мебель, иначе они перестанут перекрывать луч.

## Скрипты

- `PlayerController`: движение и камера Дениса с новым вводом и блокировкой.
- `PlayerInteraction`: поиск ближайшего объекта из центра камеры, E, открытие и закрытие осмотра, восстановление курсора и управления.
- `IInteractable`: общий контракт интерактивных объектов.
- `EvidenceItem`: данные конкретной улики и вызов окна осмотра.
- `InspectionUI`: Canvas, подсказка, текст улики, список найденных улик и кнопка закрытия.
- `EvidenceJournal`: уникальные ID и названия найденных улик между сценами в рамках одного запуска. `EvidenceAdded` вызывается только при первом нахождении. Сохранения на диск нет.
- `InteractionContentBuilder`: генератор префабов, материалов, русского шрифта и демосцены; команда подключения к выделенному игроку.
- `InteractionVerification`: проверка готовых объектов в Play Mode.

Для сюжетных событий подписываться на `EvidenceJournal.GetOrCreate().EvidenceAdded`, отписываться при уничтожении слушателя. Требуемые улики этапа проверять через `Contains(id)`. Эта задача не добавляет переходы сюжетных этапов или автоматическое открытие подвала: ключ сейчас является осматриваемой уликой.

## Проверка

**Tools → Detective → Verify Interaction Demo** открывает демосцену и запускает проверку в Play Mode. Сначала сохранить рабочую сцену. Результат пишется в `Documentation/interaction-verification.txt`. Проверяются восемь уникальных улик, выбор лучом, препятствия, дистанция, блокировка движения и обзора, закрытие кнопкой, отсутствие дублей и повторных событий, внешний запрет управления.

Дополнительно вручную проверить WASD и мышь, наведение и E, закрытие через E/Esc/кнопку, читаемость русского текста, повторный осмотр, возврат управления и переход между реальными сценами команды. У стен и мебели должны быть коллайдеры. Полное прохождение сюжетной игры не входит в эту проверку.
